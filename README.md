# PurePDF
免费浏览器端PDF工具箱，全部文件在本地浏览器处理，不上传服务器。

在线访问地址：https://purepdf.cn/

## 功能
- PDF合并
- PDF拆分
- PDF转图片
- 图片转PDF

> 水印功能正在迭代优化。

## 部署
使用 GitHub Pages 部署，主分支 main，根目录直接发布。
- robots.txt、sitemap.xml 放置仓库根目录
- 百度、Google搜索引擎做站点验证、sitemap提交

## 项目说明
- 纯前端HTML，所有PDF处理运行于浏览器本地，无后端服务。
