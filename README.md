# liu-purepdf
纯前端离线PDF工具箱，基于浏览器本地运行，文件不上传服务器。
在线实现PDF合并、拆分、压缩、添加水印、页面旋转、删除页面。

## ✨ 功能列表
- PDF合并
- PDF拆分
- PDF页面删除
- PDF页面旋转
- PDF添加文字水印
- PDF简易压缩

## 🛡 隐私优势
所有PDF解析、修改操作在本地浏览器完成，文档不会上传至第三方服务器，保护文件隐私。

## 📍 在线访问地址
https://LIU0612nn.github.io/liu-purepdf/

## 📖 使用说明
1. 打开网页，选择需要的功能
2. 上传本地PDF文件
3. 设置对应参数，点击处理
4. 自动下载处理完成的PDF

## ⚠️ 限制说明
受浏览器内存限制，建议单文件大小 ≤ 200MB。超大文件、高级PDF编辑推荐专业客户端软件。
